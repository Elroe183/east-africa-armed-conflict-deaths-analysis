East Africa Armed Conflict Deaths Analysis (2000–2025)

Project Overview

This project explores recorded deaths in armed conflicts across selected East African countries from 2000 to 2025, with a particular focus on Ethiopia.

Using Microsoft Excel, I analyzed yearly trends, compared countries, created PivotTables and visualizations, and calculated changes in recorded deaths over time.

Objectives

- Analyze annual trends in recorded armed-conflict deaths in Ethiopia.
- Compare recorded deaths across East African countries.
- Identify years with high and low recorded death counts.
- Calculate year-over-year percentage changes.
- Present key findings through charts and an Excel dashboard.

Tools Used

- Microsoft Excel: Data filtering, PivotTables, calculations, charts, and dashboard creation.
- Our World in Data: Dataset source.

Key Findings

Ethiopia: 2021–2022

- Recorded deaths in 2021: 129,481
- Recorded deaths in 2022: 164,991
- Absolute increase: 35,510
- Percentage increase: 27.42%

East Africa: 2022

Based on the countries included in my filtered dataset:

- Regional recorded deaths: 170,076
- Ethiopia's recorded deaths: 164,991
- Ethiopia's share of the regional total: 97.01%

These findings describe the recorded values in the dataset and do not, by themselves, explain the causes of changes in conflict deaths.

Visualizations

The project includes:

- Country-level line charts showing trends from 2000 to 2025.
- A bar chart comparing recorded deaths across East African countries.
- A 2022 country comparison chart.
- A chart showing each country's share of recorded deaths.
- An Ethiopia-focused analysis and key findings summary.

Data Source

The dataset was obtained from Our World in Data. The analysis uses the country, country code, year, and recorded deaths fields.

The figures reflect the dataset's definitions, coverage, and reporting limitations. They should not be interpreted as a complete count of every death or as evidence of causation.

Project Files

Conclusion

This project demonstrates how Excel can be used to explore historical data, identify trends, compare countries, and communicate findings through visualizations.

The project also highlights the importance of checking data definitions, regional coverage, and calculations before drawing conclusions.
